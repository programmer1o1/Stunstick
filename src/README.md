# Stunstick projects

Build and test these projects through [Stunstick.CrossPlatform.sln](../Stunstick.CrossPlatform.sln).

| Project | Role |
| --- | --- |
| `Stunstick.Core` | Model and archive formats, parsers, and shared data types |
| `Stunstick.App` | Decompile, compile, packaging, and Workshop workflows |
| `Stunstick.Cli` | Command-line entry point |
| `Stunstick.Desktop` | Avalonia desktop app |
| `Stunstick.SteamPipe` | Separate helper process for Steamworks.NET |
| `Stunstick.App.Tests` | Automated regression tests |

See the [repository README](../README.md) for build commands and the [platform guide](../CROSS_PLATFORM.md) for CLI examples and toolchain setup.
